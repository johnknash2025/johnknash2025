# johnkhappy

複数分野のエンジニア｜LLM農家。実世界で使えるAIアプリケーションを作っています。バックグラウンドは計算論的神経科学、根っこはちょっと物理屋です。

私が作っているのは **ローカルファーストのAIツール** です。自分のハードウェアで動き、データは手元に残り、何が検証済みで何が未検証なのかを正直に伝えるソフトウェアです。

## 予定

まだ何も作っていないアイデアです。議論のために載せています。

- **Proof of Thought**：自分で書く履歴書の代わりに、AIとの会話から作る採用プロフィール。ローカルモデルがスキルの根拠を抽出し、共有する内容は本人が承認し、企業はその根拠を検索します。

## 仕事の進め方

- プロダクトは、明文化したルールのもとでAIコーディングエージェントを使って作っています。機密保持を最優先し、隠れたテレメトリは入れず、すべての変更について「検証済み」か「未検証」かを報告します。
- 機密性のある評価は、ローカルマシンとローカルモデルで行います。
